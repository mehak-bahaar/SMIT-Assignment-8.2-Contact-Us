# SMIT Assignment 8.2 - Contact Us Page

## 📋 Description
This is a modern, responsive Contact Us page built using Bootstrap 5. The page features a clean blue design with contact information cards, company statistics, and social media links.

## 🎯 Assignment Details
- **Course**: SMIT (Saylani Mass IT Training)
- **Assignment**: 8.2
- **Topic**: Bootstrap Components and Classes

## 🚀 Features
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Contact Information Cards**: Three cards displaying email, phone, and address
- **Company Statistics**: Shows satisfaction rate, support availability, and project count
- **Social Media Links**: Facebook, Twitter, LinkedIn, and Instagram icons
- **Modern UI**: Clean and professional design with Bootstrap styling

## 🛠️ Technologies Used
- **HTML5**: Structure and content
- **Bootstrap 5.3.8**: CSS framework for responsive design
- **Bootstrap Icons**: Icon library for visual elements
- **CSS3**: Custom styling for colors and layout

## 💻 How to Use

### Method 1: Direct Opening
1. Download or clone this repository
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, etc.)
3. The page will load automatically

### Method 2: Live Server (Recommended)
1. If using VS Code, install the "Live Server" extension
2. Right-click on `index.html`
3. Select "Open with Live Server"
4. The page will open in your browser with auto-reload
